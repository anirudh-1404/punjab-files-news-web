# Punjab Files - 24h News Web Platform

Modern, responsive 24h digital news platform built with React, Vite, and designed for full MERN stack integration.

## Features
- **Header & Top Menu:** Live social links, contact info, and responsive search bar.
- **Punjabi Navigation Categories:** Full Gurmukhi navigation hierarchy with dropdowns and interactive Mega Menu.
- **Hero & Live Broadcast:** Parallax video hero banner with real-time digital clock and breaking news ticker.
- **Modular Content Architecture:**
  - World News & National News modules
  - TV Schedule & Live Stream highlights
  - Local News, Health, Sports, Travel, and Cultural modules
  - Media galleries, Video features, and Bottom carousels
- **Footer:** Authentic Punjabi tags cloud, watch+listen links, and official brand logo.

## Tech Stack
- **Frontend:** React 18, Vite, Bootstrap CSS & Vanilla CSS Design System, FontAwesome.
- **Deployment:** Vercel ready.

## Getting Started

```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```
